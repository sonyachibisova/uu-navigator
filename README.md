# Навигатор по корпусу

Интерактивная 3D-навигация по зданию: этажи, помещения, поиск нужной
аудитории. Здание собирается из данных, а не из кода: чтобы добавить
помещение, правится JSON в `data/`, код не трогается.

## Стек

TypeScript · Three.js · Vite. Сборка статическая, разворачивается на
GitHub Pages из ветки `main`.

## Разработка

```bash
npm install
npm run dev
```

| Команда | Что делает |
|---|---|
| `npm run dev` | локальный сервер разработки |
| `npm run build` | production-сборка в `dist/` |
| `npm run preview` | посмотреть собранное |
| `npm run typecheck` | проверка типов |
| `npm run lint` | ESLint |
| `npm run check-data` | валидация данных здания |
| `npm run stats` | размеры бандла против бюджета |

Отладочная панель со счётчиками FPS, draw calls, треугольников и веса —
по адресу с параметром `?debug=1`.

## Структура

| Папка | Что внутри |
|---|---|
| `src/core/` | рендер, камера, цикл кадров, состояние, отладочная панель |
| `src/building/` | сборка здания: оболочка, фасад, этажи, интерьер, подписи |
| `src/interaction/` | выбор помещения указателем |
| `src/ui/` | интерфейс |
| `data/` | данные здания: оболочка, этажи, помещения, схема, валидатор |
| `scripts/` | проверка данных и подсчёт размеров сборки |
