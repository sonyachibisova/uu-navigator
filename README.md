# Навигатор по корпусу

Интерактивная 3D-навигация по учебному корпусу: посетитель открывает
ссылку с телефона, находит аудиторию по номеру или названию и получает
маршрут до неё — с поворотами, этажами и лентой по полу.

**Живой сайт:** https://sonyachibisova.github.io/uu-navigator/

Здание собирается из данных, а не из кода: чтобы добавить помещение,
правится JSON в `data/`, код не трогается. Ни одного числа про конкретный
корпус в движке нет — он рассчитан на кампус из нескольких зданий.

## Что умеет

**Кукольный дом.** Здание раскрывается от близости камеры: грани,
обращённые к наблюдателю, растворяются, дальняя стена остаётся фоном,
кровля уходит вместе с раскрытием. Переход сглажен по времени кадра
и уважает `prefers-reduced-motion`.

**Этажи.** Кнопка этажа срезает всё выше по его потолку и подводит
камеру к плану; этаж под выбранным приглушается, чтобы здание читалось
как здание. Этажи без планировки честно об этом говорят.

**Поиск.** По номеру, по названию, по назначению помещения и по бытовым
синонимам: «туалет» находит санузлы, «библиотека» — Learning Resource
Centre, «мастерская» — мастерские. Лестницы и лифты ищутся наравне
с помещениями. Найденное помещение поднимается над планом.

**Маршруты.** Граф строится из данных — помещения, двери, коридоры,
лестницы и лифты, — путь ищется алгоритмом Дейкстры по длине в метрах.
Подъём между этажами переведён в метры пути, у лифта он дороже лестницы
на ожидание кабины. Есть режим «без лестниц» для тех, кому нужен лифт.

Маршрут показывается лентой по полу со стрелками направления и шагами
словами: «Поверните налево и идите по главному коридору — 58 м»,
«Вы на месте, дверь справа». Шаги листаются по одному, камера идёт
за шагом и сама переключает этаж на переходе.

**Точка отправления.** Спутник в здании не работает, поэтому «я тут»
приходит из адреса: `?from=stair-south-01`. Наклейки с кодами для
лестниц и лифтов печатает `npm run stickers`.

## Подписи помещений

Подпись живёт в двух видах и меняет их по экранному размеру: издалека
не показывается ничего, на плане этажа проступают крупные номера,
вблизи номер сменяется номером с названием. Все подписи этажа лежат
в одном атласе и рисуются одним вызовом — иначе этаж стоил бы
двадцать девять вызовов из полутора сотен.

## Бюджеты и замер

Замер снимается в headless-браузере на собранной сборке с перехватом
gl-вызовов; отладочная панель с теми же счётчиками — по адресу
с параметром `?debug=1`.

| Состояние | Draw calls | Лимит |
|---|---|---|
| общий вид | 89 | 150 |
| раскрыто целиком, с подписями | 104 | 150 |
| этаж 4 | 68 | 150 |
| этаж 5 | 90 | 150 |

Треугольники в худшем кадре — около 13 000 при лимите 300 000, вес
загруженных ресурсов — 649 КБ при лимите 3 МБ, JS — 176 КБ gzip.
Теневой проход считается только когда меняется видимость геометрии,
а не в каждом кадре.

## Стек

TypeScript · Three.js · Vite. Сборка статическая, разворачивается
на GitHub Pages из ветки `main`.

## Разработка

```bash
npm install
npm run dev
```

| Команда | Что делает |
|---|---|
| `npm run dev` | локальный сервер разработки |
| `npm run build` | production-сборка в `dist/` |
| `npm run preview` | посмотреть собранное |
| `npm run typecheck` | проверка типов |
| `npm run lint` | ESLint |
| `npm run check-data` | валидация данных здания |
| `npm run stats` | размеры бандла против бюджета |
| `npm run stickers` | лист A4 с кодами для лестниц и лифтов |

## Структура

| Папка | Что внутри |
|---|---|
| `src/core/` | рендер, камера, цикл кадров, состояние, кукольный дом, отладочная панель |
| `src/building/` | сборка здания: оболочка, фасад, этажи, интерьер, подписи, лента маршрута |
| `src/routing/` | граф путей по зданию и поиск маршрута |
| `src/interaction/` | выбор помещения указателем |
| `src/ui/` | интерфейс: поиск, этажи, карточка помещения, маршрут |
| `data/` | данные здания: оболочка, этажи, помещения, схема, валидатор |
| `scripts/` | проверка данных, размеры сборки, печать наклеек |

## Чего пока нет

- **Планировок этажей 1–3.** Планы есть только для четвёртого и пятого,
  остальные показываются глухими объёмами. Из-за этого маршрут нельзя
  построить от входа — только между размеченными этажами.
- **Настоящей модели.** Геометрия процедурная, собрана по чертежам;
  визуальный язык появится вместе с моделью от художника.
- **Расписания.** Схема события описана, источник данных ждём от школы.
